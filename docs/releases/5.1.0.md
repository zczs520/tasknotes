# TaskNotes Time 5.1.0

## Added

- Added desktop goal management with Markdown-backed goals, parent/child goal groups, tag-based task attribution, pace-aware progress in Kanban and time statistics, and manually confirmed milestone tiers.

## Changed

- Renamed the plugin and its iOS companion from TASKquence to TaskNotes Time, with updated author metadata, documentation, and product imagery. The internal plugin ID and existing vault paths remain unchanged for upgrade compatibility.
- Refined time statistics milestones into stage cards showing the current value, next-stage target, remaining gap, update age, and stage progress. Historical tagged time now becomes visible immediately when a newly created goal adopts an existing tag, and time-record rows provide a direct editor.
- Simplified the Kanban goal rail by removing the redundant “All goals” link and the explanatory paragraph beneath tag distribution.
- Matched Kanban goal rails and overlays to the product design, including offline numeric typography, text-only goal links, compact milestone updates, completion items, and achieved evidence. Centered goal management, removed the reason field from creation and details while preserving existing note content, and added hover and focus feedback to milestone creation.
- Matched goal management to the product design with compact borderless filters, plain scope labels, distinct goal colors, and tier-aware milestone cards that remain editable and unchanged when switching reporting periods. Creation and details share the same milestone type and tier editor.
- Statistics without visible goal progress now use a full-width single-column layout, including snapshots with attribution goals but no displayable goal panel.
- Assigned distinct, stable identity colors to tags and goals. Task ranking, timelines, and time records now consistently use the task's primary tag color.
- Refined goal progress, tag distribution, and task ranking typography and spacing while preserving offline numeric fonts and milestone interactions.
- Added history-backed zero-investment notes and milestone investment totals to time statistics.
- Redesigned desktop goals with a compact list, instant-edit details, recoverable deletion, period-aware child targets, pause and resume controls, and read-only historical views.
- Removed quick input from task creation while keeping the title, structured properties, and details editor.
- Changed documentation automation to validate the generated site without publishing it to GitHub Pages.
- Replaced the Kanban goal cards with a persistent compact strip that can expand over the board or close into a filter-bar badge.

## Fixed

- Localized the goal-management list, filters, period controls, table headings, milestone summary, empty state, and accessibility labels for English and Chinese UI modes.
- Fixed Kanban flashing on goal overlay expansion and collapse. Presentation changes now update only the goal surface without requerying tasks, clearing columns, remounting cards, or resetting board scroll.
- Fixed goal details being unscrollable and deletion confirmation being inaccessible below the modal. Confirmation now appears below the fixed header with child-preservation choices, duplicate-submit protection, and recoverable file deletion.
- Corrected empty numeric achievement records being counted as completed milestones and protected inline updates from blank values and failed writes.
- Retained zero-investment task tags in period statistics and synchronized tag and ranking colors with their goal attribution.
- Prevented asynchronous goal baseline updates from rebuilding the form and interrupting typing. Added explicit validation feedback and individual milestone removal controls.
