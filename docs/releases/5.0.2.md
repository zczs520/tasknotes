# TASKquence 5.0.2

## Fixed

- Removed source-code patterns that blocked Obsidian's automated community-plugin review.
- Restored the archive and delete controls in the autosaving task editor.
- Time blocks created from date-only scheduled tasks now keep the intended calendar date across time zones.
- Kanban date filters now keep the configured columns and swim lanes visible when the selected period has no tasks.
- Kanban boards now keep newly discovered swim lanes hidden until they are explicitly enabled, while preserving the visibility of existing lanes.
- Notes converted into tasks now default their scheduled date to today and inherit every tag already present in the note, moving inline tags into task properties so they are not shown twice.
- New tasks created from a Base view now inherit custom frontmatter filters, so they remain visible on boards that identify tasks with fields such as `taskType: task`.
- Clicking an inline task link now opens its task editor immediately instead of first revealing the underlying Wiki link markup.
- Kept task-note time records and embedded relationships stable while editing or syncing notes. Time records update when sessions start, stop, or are edited, without continuously refreshing the footer or resetting the relationships view.
