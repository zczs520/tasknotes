# TaskNotes Time 5.1.1

## Changed

- Goal management now batches vault-driven refreshes, reuses unchanged goal files, keeps the current surface visible while data reloads, and applies status filters without rescanning the vault. Goal creation computes all tag baselines in a single task scan.
- Milestone progress nodes now show their tier values and units directly, with optional units editable during creation and in goal details. Current-day statistics include the same editable pending-milestone section as week and month views.
- Parent goals in the Kanban goal rail and overlay now display their combined child time budget beside the invested time.
- Kanban column groups now sit centered within the board in both flat and swimlane layouts, while narrow boards retain accessible horizontal scrolling.

## Fixed

- Historical goal statistics now attribute matching tagged time even when the goal was created after the selected period.
- Tag distribution now hides labels with no tracked time in the selected period.
