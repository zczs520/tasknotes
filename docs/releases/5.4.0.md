# TaskNotes Time 5.4.0

## Added

- Open goal management as a regular Base file at `TASKquence/Views/goals.base`, with support for links and embeds. New installations create it by default; existing users receive the missing file when automatic Base creation and goal management are enabled. Existing goal notes, custom file paths and edited Base files are preserved. See [default Base templates](https://tasknotes.dev/reference/default-base-templates/#goalsbase).
- Completion milestones support multiple named stages. Confirm each stage separately to record its completion date and cumulative invested hours.
- Edit existing milestone names, units and tiers from goal details. Retained tiers keep their completion records, and legacy single-stage milestones can be extended with more stages.

## Fixed

- Numeric milestone undo now rolls the current value back to the previous achieved tier and clears completion records for the undone tier and later tiers. Undoing every tier resets progress to zero and corrects the daily progress history, keeping dashboards and statistics consistent.
- Milestone detail timelines display dates only for achieved tiers. Pending tiers no longer show duplicate placeholder labels, and milestones with missing achievement records no longer claim full completion.
