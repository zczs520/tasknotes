# TaskNotes Time 5.3.0

## Added

- Added period-filtered milestone progress to time statistics. Stage achievements are grouped by milestone and day, progress-only updates remain visible in their recorded period, and completed historical periods stay read-only.
- Added per-view controls for showing pending milestone updates in the current week, month, and year.

## Changed

- Parent goal rows now show the combined target time of their child goals. Removed redundant goal-attribution helper copy from tag distribution and task ranking.

## Fixed

- Kept collapsed Kanban swimlane headings aligned with the first status column as the configured column width changes.
