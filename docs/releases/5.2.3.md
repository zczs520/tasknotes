# TaskNotes Time 5.2.3

## Added

- Added an “Edit time entries” action to the time-record section on task notes, opening the existing time-entry editor.

## Changed

- Split the task-note footer visibility controls: “Subtasks & relationships” now controls only that section and defaults off, while the new “Time entries” setting independently controls the bottom time-record card and defaults on. Existing combined settings migrate once to these defaults.
- Task-note timer, time-record, and subtask surfaces now follow the active Obsidian theme when TASKquence theme colors are disabled.
- Simplified active timer controls and removed the rounded container from active time-statistics rows.
- Aligned the Kanban goal strip with the board edges and kept collapsed swimlane headings left-aligned.

## Fixed

- Unified active timer hover feedback across task cards and the floating timer: the timer status, “Stop”, and “Complete” now respond independently with readable semantic feedback instead of white text or unchanged states.
