# TASKquence 5.0.3

## Added

- Added Chinese and English getting-started, Kanban, and iOS companion guides without overwriting existing notes.
- Added view switches under **General → Views & base files**. Kanban, time statistics, and task creation shortcuts are enabled by default; other views can be enabled when needed.
- Added a Kanban column status menu for editing status names, colors, icons, and completion behavior, or deleting a status without deleting task notes.
- Added six bilingual example tasks for work, study, creativity, fitness, home, and leisure, with sample time entries for exploring every statistics period.
- Added a button to create or restore missing examples without overwriting existing notes.

## Changed

- Tasks now consistently use `taskType: task`; Kanban and time statistics share this identity, and new tasks default to `TASKquence/Tasks`.
- Kanban now defaults to tag swimlanes, shows newly discovered lanes, enables search and date filters, and supports task creation from empty columns and search results.
- Existing task data now prevents automatic example creation, and the decision is remembered to avoid unexpected examples later.
- The project README now opens in English and provides a direct jump to the complete Chinese version.

## Fixed

- Kept English time-entry totals fully visible in the time-statistics summary and made example prefixes bilingual throughout generated sample tasks.
- Daily time-statistics blocks now use the same tag color as their labels, including short entries that previously appeared white.
- Refreshed the current Kanban board immediately after editing or deleting a status while preserving its active view state.
- Migrated saved legacy default view paths from `TaskNotes/Views` to `TASKquence/Views` while retaining existing Base contents and custom paths.
