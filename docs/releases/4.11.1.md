# Dayquence 4.11.1

Dayquence 的首个独立发行版。它基于 TaskNotes，并面向个人任务规划、专注执行和时间复盘进行了重新设计。

## Added

- Added Chinese and English first-run guides. New users receive both pages, and Dayquence automatically opens the guide matching the current interface language.
- Added a compact floating active-task control with live elapsed time and separate Stop and Complete actions.
- Added a unified time statistics dashboard for day, week, month, and year views, including timelines, heatmaps, task rankings, tag distribution, and individual time records.
- Added optional Kanban search and scheduled, created, or completed date filters.
- Added Dayquence iOS life-event sync support alongside calendars, Pomodoro, and task time tracking.

## Changed

- Renamed the user-facing plugin to **Dayquence**, updated the author to **zhuxiaocong**, and moved release checks to the independently maintained repository.
- Rebuilt task creation and editing as a single-column task sheet. Tasks are created immediately, all edits autosave continuously, and the header provides a direct Open note action.
- Improved natural-language capture, including Chinese date expressions such as “明天下午三点”.
- Redesigned Kanban with soft color-coded columns, standalone cards, collapsible and reorderable swimlanes, quick scheduled-date changes, and task creation that inherits the current column and swimlane.
- Connected configured in-progress status changes with time tracking. Entering the status can start timing; leaving it stops the active timer.
- Refined task-note action cards and system properties so active timing controls remain visible and time entries are summarized instead of displaying raw data.
- Rewrote the project README in Chinese and English with current feature screenshots and installation instructions.

## Fixed

- Fixed active timers, saved task status, floating controls, and task-note controls drifting out of sync across different task entry points.
- Fixed Kanban drag-and-drop, custom date filtering, saved status order, hidden swimlanes, and tag-based swimlane refresh behavior.
- Fixed task-modal autosave after renaming root-level tasks and improved tag suggestions across the entire vault.
- Fixed newly created tasks losing the editable empty `tags` property.
- Fixed task relationships created from the Relationships widget not inheriting the correct parent and tags.

## Installation

Download `main.js`, `manifest.json`, and `styles.css` from the GitHub Release assets and place them in:

```text
.obsidian/plugins/tasknotes/
```

Then enable **Dayquence** in Obsidian's community plugin settings.

Dayquence retains the `tasknotes` plugin ID and `TaskNotes/` data directory for compatibility with existing vaults.

This is the first independent Dayquence release, based on the open-source TaskNotes project. It includes bilingual onboarding, autosaving task capture, a redesigned Kanban, active-task controls, unified time statistics, calendars, Pomodoro, time tracking, and Dayquence iOS life-event sync.
